# kursi-tojik — правила проекта

## ЧЕГО НЕ ДЕЛАТЬ
- Не усложнять. Если задача решается в 10 строк — решай в 10.
- Не додумывать. Неясно — спроси.
- Не делать изменений «на всякий случай».
- Не говорить «готово», пока не перепроверил.

## СТЕК
- web/ — Vite + TypeScript, чистый TS без React/Vue
- worker/ — Cloudflare Worker (TypeScript, Wrangler)
- Данные: web/src/data/*.json (banks.json, transfers.json)

## СТИЛЬ
- TypeScript strict
- Никаких any
- Комментарии на русском
- Функции ≤ 50 строк
- Никаких внешних UI-библиотек без спроса

## АРХИТЕКТУРА
- Worker — только CORS-прокси для НБТ (nbt.tj), парсинг XML из windows-1251
- Web — статика, никаких серверов
